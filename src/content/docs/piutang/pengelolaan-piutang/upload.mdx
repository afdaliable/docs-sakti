Menu Upload digunakan untuk memudahkan perekaman transaksi
dengan volume besar dalam satu waktu tertentu.

<MenuSakti />

## Langkah

<Steps>

1. Pilih menu **Piutang > Pengelolaan Piutang > Upload >
   Upload**.
2. Unggah file ADK .csv transaksi yang sudah diisi sesuai format
   masing-masing jenis transaksi.

</Steps>

## Ketentuan

- Transaksi yang dapat direkam menggunakan fitur upload ini
  adalah: Settlement SBS dan via Data Upload, Koreksi TAB,
  Surat Peringatan (SP), Koreksi Normal, dan Koreksi Selisih
  Kurs.
- File unggah menggunakan ADK .csv dengan pemisah kolom
  menggunakan tanda "|"; format file dapat diunduh pada tautan
  di bagian Sumber.
- Jurnal yang terbentuk sama dengan jurnal dari masing-masing
  transaksi jika direkam secara manual.

Format kolom tiap jenis file ADK:

| Jenis file | Kolom |
|---|---|
| Koreksi Normal | kode_satker, no_piutang, jumlah_koreksi, no_dok, tgl_koreksi, nilai penyisihan, jenis_koreksi, uraian |
| Koreksi Selisih Kurs | kode_satker, no_piutang, jumlah, no_dokumen, tgl_dokumen, nilai_penyisihan, jenis_koreksi, uraian |
| Koreksi TAB | kode_satker, no_piutang, jumlah_koreksi, no_dok, tgl_settlement, jenis_koreksi, uraian |
| Settlement | kode_satker, no_piutang, no_dok_settlement, tgl_settlement, nilai_settlement, sumber_data, nilai_valas |
| Surat Peringatan (SP) | kode_satker, no_piutang, SP Ke, no_dokumen, tgl_dokumen, Uraian |

Petunjuk pengisian kolom jenis koreksi:

| Kode Jenis Koreksi | Deskripsi Jenis Koreksi |
|---|---|
| 0 | Koreksi Normal |
| 1 | Koreksi Selisih Kurs |
| 3 | Koreksi TAB |

Petunjuk pengisian kolom jenis settlement:

| Kode Jenis Settlement | Deskripsi Jenis Settlement |
|---|---|
| 2 | Settlement via Data Upload |
| 3 | Settlement SBS |
