Menu **ADK Supplier** pada fitur KPPN digunakan untuk memproses ADK
Supplier yang sudah masuk ke KPPN, mulai dari unduh dan pemeriksaan
oleh petugas FO, verifikasi oleh user MO, sampai persetujuan oleh
user Kasi PD/PDMS.

<MenuSakti />

## Prasyarat

- Role yang dibutuhkan: petugas FO, user MO, dan user Kasi PD/PDMS
  (Approver).
- Mapping user FO dan MO sudah dilakukan — lihat [Memetakan Petugas
  Portal KPPN](/kppn-bun/mapping-petugas-portal-kppn/).

## Alur proses

1. Petugas FO — mengunduh ADK Supplier beserta dokumen pendukung,
   lalu meneruskan ke user MO atau menolaknya.
2. User MO — mengunduh dan memverifikasi ADK, lalu meneruskan ke
   user Kasi PD/PDMS atau menolaknya.
3. User Kasi PD/PDMS — menyetujui atau menolak ADK.

## Langkah

### Pemrosesan oleh petugas FO

<Steps>

1. Untuk melakukan proses ADK Supplier yang sudah masuk ke KPPN,
   login menggunakan user petugas FO.
2. Masuk ke menu **KPPN > Pencairan Dana > Proses > ADK Supplier**.
3. Filter digunakan untuk melakukan pencarian ADK Supplier yang
   telah dikirim oleh satker; setelah melakukan pengisian kolom
   filter, klik tombol **Filter** untuk melanjutkan pencarian atau
   klik tombol **Reset** untuk mengembalikan ke filter awal.
   Keterangan filter:

   | Filter | Keterangan |
   |---|---|
   | KPPN | Kode dan Nama KPPN user FO/MO/Kasi bertugas |
   | Kode Satker | Kode satker mitra kerja KPPN pengirim ADK Supplier |
   | Nama ADK | Nama ADK supplier yang dikirimkan oleh satker mitra kerja |
   | Tanggal Upload | Tanggal Upload ADK Supplier yang diupload oleh satker mitra kerja |
   | Petugas | User ID petugas FO/MO/Kasi |

4. Status awal adalah **Belum Proses**; klik tombol download untuk
   mengunduh ADK supplier beserta dokumen pendukungnya. Apabila
   akan melakukan download ADK supplier atau dokumen pendukung
   saja, klik tanda panah ke bawah untuk menampilkan opsi data yang
   akan diunduh.
5. Setelah FO melakukan download baik ADK maupun dokumen pendukung,
   status ADK akan berubah menjadi **Proses ADK**, posisi ADK akan
   terisi **FO Validator**. Pada kolom petugas akan muncul nama
   petugas FO yang melakukan unduh ADK. Pada bagian kanan, di
   bagian bawah tombol Download, akan muncul 2 tombol tambahan —
   untuk meneruskan ADK ke user MO dan untuk melakukan penolakan
   ADK di user FO.
6. Apabila ADK disetujui oleh FO, klik tombol **Teruskan ke MO**
   untuk melanjutkan ADK ke user staff MO. Dalam hal adanya
   penolakan baik secara manual ataupun karena validasi SPAN, klik
   tombol **Tolak ADK** dan akan muncul form isi keterangan tolak
   ADK; pada form tersebut isikan keterangan penolakan dan lampiran
   penolakan (opsional).

</Steps>

### Pemrosesan oleh user MO

<Steps>

1. Pada user MO akan ditampilkan seluruh ADK supplier yang
   dikirimkan oleh satker mitra kerja; namun ADK supplier yang
   dapat diproses oleh MO adalah ADK yang sudah diteruskan oleh FO
   ke MO dengan posisi ADK **MO Verifikator**.
2. User MO dapat melakukan download ADK supplier maupun dokumen
   pendukung untuk melakukan verifikasi kesesuaian data supplier
   yang diproses. Data yang dapat didownload oleh user MO adalah
   data supplier yang sudah didownload oleh user FO dan sudah
   diteruskan ke user MO.
3. Dalam hal data supplier disetujui, lanjutkan dengan klik tombol
   **Teruskan ke APR** agar data supplier tersebut muncul di user
   Kasi PD/PDMS. Apabila terjadi penolakan, user MO menekan tombol
   **Tolak ADK** dan mengisikan informasi penolakan pada form **Isi
   Keterangan Tolak ADK**.
4. User MO akan tercantum pada kolom Petugas setelah klik tombol
   **Teruskan ke APR** dan posisi ADK akan berubah menjadi
   **Approver**.

</Steps>

### Persetujuan oleh user Kasi PD/PDMS

<Steps>

1. Pada user Kasi PD/PDMS akan ditampilkan semua ADK yang
   dikirimkan oleh satker mitra kerja; namun yang dapat diproses
   lebih lanjut oleh user Kasi adalah ADK dengan posisi ADK
   **Approver**.
2. User Kasi dapat melakukan download ADK supplier maupun dokumen
   pendukungnya untuk memastikan kesesuaian data ADK supplier yang
   diproses. Dalam hal ADK supplier berhasil diproses, klik tombol
   **Setujui ADK**. Dalam hal terdapat penolakan, klik tombol
   **Tolak ADK** dan lanjutkan dengan mengisi form **Isi Keterangan
   Tolak ADK**.

</Steps>
