Fitur KPPN pada aplikasi SAKTI memudahkan petugas Fo/Mo KPPN dalam
memproses ADK SPM, Renkas Harian, dan Koreksi SPM Satker.
Pengembangan fitur ini mengadopsi aplikasi yang sudah familiar bagi
KPPN, yaitu aplikasi E-SPM.

| Keterangan | Isi |
|---|---|
| Modul | Fitur KPPN (Portal SAKTI) |
| Role User | Operator, Validator, Reviewer, Approver |
| Modul lain terkait | PEM |
| Transaksi yang terkait | PEM: Renkas Harian, ADK SPM, Koreksi SPM, Monitoring ADK SPM |
| Dokumen input | SPP/SPM |
| Output | ADK PMRT, Dokumen Pendukung |
| Validasi | Pengiriman ADK SPM Satker |
| Petunjuk teknis terkait | ADM – Pendaftaran User SAKTI; PEM – Perekaman SPM |

## Prasyarat

- Role yang dibutuhkan: Operator, Validator, Reviewer, dan
  Approver (role user menurut juknis).

## Alur proses

1. **Proses ADK SPM** — ADK SPM yang dikirim satker diperiksa
   petugas Fo, divalidasi petugas Validator (unggah ADK PMRT ke
   SPAN), diperiksa kembali Reviewer (Mo), lalu disetujui Kasi
   Pencairan Dana (Approver).
2. **Proses ADK SPM Koreksi** — alurnya tidak melalui petugas
   Mo/Reviewer; pemrosesan oleh Validator/Fo_Validator langsung ke
   Kasi Pencairan Dana.

## Ketentuan

- Pendaftaran pengguna SAKTI level KPPN disampaikan ke Admin Pusat
  (SITP).
- Setelah mendaftarkan user SAKTI, lakukan perekaman peran pada Fo
  maupun Mo oleh Kasi PD.
- Mapping dilakukan oleh Kasi Pencairan Dana pada menu **Mapping
  User Portal**.
- Mapping dilakukan hanya untuk user Validator dan Reviewer.
- Perekaman mapping pasangannya dilakukan secara manual.
- Satu user portal tidak dapat direkam lebih dari satu kali pada
  mapping user Portal.
- Fo dan Validator berperan sebagai operator pada aplikasi SAKTI
  (`oprkppn_kdsatker_nip`).
- Reviewer berperan sebagai Validator pada aplikasi SAKTI
  (`valkppn_kdsatker_nip`).
- Kasi Pencairan Dana berperan sebagai Approver pada aplikasi SAKTI
  (`aprkppn_kdsatker_nip`).
- Apabila data ADK PMRT tidak muncul pada menu SPM, dimungkinkan
  karena belum dilakukan perekaman peran atau mapping Validator dan
  Reviewer.
- Fitur KPPN saat ini baru tersedia untuk menu Proses ADK SPM,
  Koreksi SPM, dan Renkas Harian.
