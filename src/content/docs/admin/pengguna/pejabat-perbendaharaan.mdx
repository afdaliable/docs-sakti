Menu **Pejabat Perbendaharaan** digunakan untuk merekam data pejabat
perbendaharaan satker dan untuk mendaftarkan One Time Password (OTP)
SAKTI bagi modul Pelaksanaan.

<MenuSakti />

## Pejabat yang direkam

Menu pejabat digunakan untuk merekam Pejabat Perbendaharaan, di antaranya:

- Kuasa Pengguna Anggaran (KPA)
- PPSPM
- PPK
- Bendahara
- Kepala Kantor (apabila berbeda dengan KPA)
- Operator (untuk TTE Dokumen Pendukung)

Beberapa data pejabat terisi secara otomatis berdasarkan data pengguna,
di antaranya NIP, NIK, NPWP, Nomor HP, dan Email.

## Aturan checkbox PPK Umum

- Untuk satker yang hanya memiliki 1 PPK, checkbox **PPK Umum** di menu
  pejabat wajib dicentang.
- Apabila terdapat lebih dari 1 PPK, harus ada 1 PPK yang bertindak sebagai
  PPK umum. PPK lain (PPK khusus) dibagi pagu pada menu pembagian pagu per
  PPK (modul anggaran).

## Hal yang perlu diperhatikan

- Isian data pada Pejabat dan Data Penandatangan harus sama.
- Untuk perubahan user Pejabat Perbendaharaan, admin satker terlebih
  dahulu menghapus Pejabat Perbendaharaan di referensi pejabat. Pastikan
  pejabat tersebut tidak memiliki transaksi yang menggantung.

## Status pejabat

Status pada referensi pejabat memiliki arti sebagai berikut:

| Status | Arti |
|---|---|
| Baru | Muncul setelah referensi pejabat direkam. |
| Kirim | Muncul setelah data pada referensi pejabat dikirim ke KPPN oleh user KPA. |
| Setuju CSO | Muncul setelah Pelaksana PDMS/MSKI melakukan persetujuan aktivasi OTP tingkat pelaksana (admuser). |
| Aktif | Muncul setelah Kasi PDMS/MSKI melakukan persetujuan aktivasi OTP tingkat kepala seksi (apruser). |
| Blokir | Muncul apabila kewenangan OTP diblokir. |

Pada juknis versi 2022, menu ini berada di jalur **Administrasi > Umum >
Jabatan > Pejabat**; pada aplikasi saat ini menu tersebut berada di
**Administrasi > Pengguna > Pejabat Perbendaharaan**.
