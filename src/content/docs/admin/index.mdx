Admin SAKTI berperan besar pada aplikasi SAKTI. Ibarat pemegang kunci,
user-user dan referensi ke depannya dikelola melalui user admin. Admin
berfungsi mengelola manajemen user/pengguna pada aplikasi SAKTI sesuai
tipe dan kewenangannya. Modul ini memuat panduan pengelolaan pengguna,
referensi, mapping, penandatangan, PKIPA, dan monitoring.
