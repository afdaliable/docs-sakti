Menu **Monitoring Login Satker** digunakan untuk melihat pengguna yang
sedang login serta menghapus session dari user admin.

<MenuSakti />

Saat ini penghapusan session login juga dapat dilakukan secara mandiri
oleh masing-masing pengguna saat login melalui fitur **Buka Akun**.

## Masalah umum

<details>
<summary>Saat login muncul "Error Pengguna Sudah Login"</summary>

Klik **Buka Akun**, masukkan password untuk membuka session.

</details>

<Aside type="caution" title="Perlu verifikasi">
Juknis 2022 menyebut menu ini sebagai **Administrasi > Admin >
Pengelolaan Pengguna dan Kontrol Akses > Monitoring Login Satker**.
Menu tersebut hanya ada di juknis 2022; materi ini tidak tercantum pada
deck juknis 2024.
</Aside>
