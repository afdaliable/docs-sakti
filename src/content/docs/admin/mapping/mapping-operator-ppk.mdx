Mapping Operator Pelaksanaan – PPK digunakan untuk menghubungkan antara
operator Pembayaran dan Komitmen dengan PPK-nya.

<MenuSakti />

## Prasyarat

- Role yang dibutuhkan: **Admin Satker** — juknis mencantumkan Mapping
  Operator Pelaksanaan – PPK dan Mapping Operator Anggaran – PPK dalam
  lingkup tugas Admin Satker.

## Ketentuan

- Staff operator pembayaran hanya dapat mengakses pagu dari PPK yang
  dihubungkan.
- Apabila Mapping Operator-PPK tidak dilakukan, user operator pembayaran
  tidak dapat membuat SPM.
- Penghapusan pejabat turut menghapus mapping Operator – PPK, sehingga
  mapping perlu direkam ulang setelah proses pemutakhiran user dan OTP
  selesai (lihat [Memutakhirkan Data
  Pengguna](/admin/pengguna/pemutakhiran-data-pengguna/)).

Pada menu tersedia tombol mapping. Tab Operator – PPK hanya merupakan
perbedaan perspektif tampilan saja.

## Mapping Operator Anggaran

Mapping Operator Anggaran – PPK digunakan untuk menghubungkan antara
operator Anggaran dengan PPK-nya. Mapping Operator Anggaran dilakukan
pada dua menu berikut:

1. **Administrasi > Mapping > Mapping Opr. Anggaran-PPK**
2. **Penganggaran > RUH > Pembagian Pagu per Operator**

<Aside type="caution" title="Perlu verifikasi">
Juknis 2024 menulis label **Mapping Operator Pelaksanaan dan PPK** /
**Mapping Operator Anggaran dan PPK** dan **Anggaran > RUH > Pembagian
Pagu Per Operator**; menu aplikasi memakai label singkat seperti pada
artikel ini. Juknis tidak merinci langkah klik demi klik.
</Aside>
