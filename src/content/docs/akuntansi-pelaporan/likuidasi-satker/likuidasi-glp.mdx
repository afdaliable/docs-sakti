Menu Likuidasi Satker pada modul GLP digunakan untuk
melakukan Likuidasi Keluar dan Likuidasi Masuk Neraca
sebagai akibat pengakhiran/pembubaran Satker. Dokumen
input: BA Likuidasi; output: Laporan Keuangan.

<MenuSakti />

## Prasyarat

- Role yang dibutuhkan: OPR (dan user Admin untuk setup
  likuidasi).
- Modul Persediaan, Modul Aset Tetap, dan Modul Piutang
  telah dilakukan likuidasi.

## Langkah

### Setup likuidasi (user Admin)

<Steps>

1. Login sebagai Admin pada menu **Administrasi > GL dan
   Pelaporan > Setup Likuidasi**, lalu klik **Rekam**.
2. Isi data setup likuidasi Satker: Periode (bulan saat
   likuidasi keluar), Tanggal Mulai dan Tanggal Akhir
   (rentang tanggal buku yang dapat dipilih), Satker Asal,
   Satker Tujuan, UAKPB Tujuan, Status Likuidasi (pilih
   **belum selesai**), dan Keterangan — lalu **Simpan**.

</Steps>

### Likuidasi Keluar

<Steps>

1. Login sebagai user operator GLP Satker yang dilikuidasi.
2. Pilih menu **GL dan Pelaporan > Likuidasi Satker >
   Likuidasi Keluar** (jalur menurut juknis), lalu klik
   **Rekam**.
3. Cari Satker asal, pilih Tanggal, kemudian **Simpan > Ya >
   Oke**.

</Steps>

### Likuidasi Masuk

Pastikan telah dilakukan Likuidasi Keluar Modul GLP Satker
asal dan periode GLP Satker Likuidasi Masuk terbuka.

<Steps>

1. Login sebagai user operator GLP Satker Likuidasi Masuk.
2. Pilih menu **GL dan Pelaporan > Likuidasi Satker >
   Likuidasi Masuk** (jalur menurut juknis), lalu klik
   **Rekam**.
3. Proses Likuidasi Masuk — proses Modul GLP selesai.

</Steps>

<Aside type="caution" title="Perlu verifikasi">
Daftar menu SAKTI hanya memuat **Likuidasi Keluar** dan
**Likuidasi Masuk** di bawah **Likuidasi Satker**; jalur menu
pada artikel ini memakai simpul induk.
</Aside>
