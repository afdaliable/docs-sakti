SPM LS Banyak Penerima 237 BAST digunakan untuk membayar tagihan
yang sifatnya non gaji dan non kontraktual yang menggunakan Berita
Acara Serah Terima Barang (BAST), terutama tagihan yang menggunakan
akun Belanja Modal/Aset (53).

<MenuSakti />

## Prasyarat

- Role yang dibutuhkan: **Operator SPP/SPM** dan **Operator
  Pembayaran** (perekaman dan cetak), **PPK** (validasi SPP dan ADK
  SPP), **PPSPM** (validasi SPM dan ADK SPM).
- Supplier tipe 3 dan tipe 6 telah direkam pada modul Komitmen —
  lihat [Supplier](/komitmen/ruh/pencatatan-suplier/).
- BAST Non Kontraktual telah direkam lebih dulu pada modul Komitmen;
  perekaman BAST mengakomodir penginputan kode barang aset — lihat
  [Mencatat BAST Non Kontraktual](/komitmen/ruh/pencatatan-bast/bast-non-kontraktual/).
- Dokumen input: SPP SPM LS Banyak Penerima BAST.

## Alur proses

1. Operator — input supplier tipe 3 dan 6, mengacu pada juknis
   input supplier.
2. Operator — input BAST Non Kontraktual, mengacu pada juknis input
   BAST.
3. Operator SPP/SPM — input SPP.
4. Operator Pembayaran — cetak SPP.
5. PPK — setuju SPP.
6. PPK — membuat ADK SPP.
7. Operator Pembayaran — cetak SPM.
8. Operator Pembayaran — upload dokumen pendukung.
9. PPSPM — setuju SPM.
10. PPSPM — membuat ADK SPM.
11. KPPN — memproses SPM menjadi SP2D.
12. Operator Pembayaran — mencatat SP2D.

## Langkah

### Merekam SPP (Operator SPP/SPM)

Login menggunakan user operator SPP/SPM.

<Steps>

1. Buka menu **Pembayaran > RUH Pembayaran > Catat/Ubah SPP**.
2. Pilih jenis SPP **237 SPM LS BANYAK PENERIMA BAST**.
3. Klik tombol **Tambah**.
4. Pilih **BAST Non Kontraktual**.
5. Klik tombol **Pilih** — masuk ke halaman Perekaman SPP.
6. Pilih **Dasar Pembayaran**.
7. **Uraian pembayaran** terisi otomatis sesuai BAST Non Kontraktual
   yang dipilih.
8. Pilih **RPD** yang telah dibuat sebelumnya apabila nilai SPM
   melebihi Rp1 miliar (sesuai PMK Nomor 197/PMK.05/2017 tentang
   Rencana Penarikan Dana, Rencana Penerimaan Dana, dan Perencanaan
   Kas); lewati apabila nilai SPM kurang dari Rp1 miliar.
9. Klik tombol **Supplier Header** untuk memilih supplier header.
10. Klik tombol **Tambah** untuk menambah supplier.
11. Klik tombol **Upload File CSV** untuk mengunggah file ADK CSV
    berisi nama penerima, jumlah uang yang diterima, dan data lain
    yang berkaitan — pastikan nama supplier header dalam file ADK
    CSV sama dengan supplier header yang dipilih. Apabila tidak
    menggunakan file CSV, input nilai pembayaran secara manual untuk
    masing-masing penerima; pastikan nilai yang diinput adalah nilai
    bersih yang diterima masing-masing penerima.
12. Klik **Akun Potongan/Penerimaan** lalu klik tombol **RUH Akun**
    untuk menginput akun potongan apabila ada potongan.
13. Klik tombol **Simpan** apabila tidak ada potongan, atau apabila
    perekaman potongan telah selesai direkam.

</Steps>

### Cetak SPP (Operator Pembayaran)

Login menggunakan user operator pembayaran.

<Steps>

1. Buka menu **Pembayaran > Cetak > Mencetak SPP**.
2. Pilih SPP yang ingin dicetak.
3. Pilih PPK.
4. Pastikan tempat dan tanggal telah sesuai.
5. Klik tombol **Unduh** untuk mencetak SPP.
6. Klik tombol **SSP** apabila ingin mencetak SSP.

</Steps>

### Setuju SPP (PPK)

Login sebagai pengguna PPK selaku validator pada modul Pembayaran.

<Steps>

1. Buka menu **Pembayaran > Validasi > Validasi SPP**.
2. Pilih SPP yang ingin divalidasi.
3. Klik tombol **Unduh Pra Cetak** untuk mencetak SPP yang akan
   divalidasi.
4. Klik tombol **Setuju** untuk menyetujui SPP.
5. Klik tombol **Batal** apabila ingin membatalkan validasi atas SPP
   yang sudah divalidasi.

</Steps>

### Membuat ADK SPP (PPK)

<Steps>

1. Buka menu **Pembayaran > ADK > ADK SPP OTP**.
2. Pilih SPP yang ingin dibuat ADK SPP dengan menceklis kolom pilih;
   dapat memilih lebih dari satu SPP sekaligus apabila diperlukan.
3. Klik tombol **Proses**.
4. Klik tombol **Req OTP via SMS** untuk meminta kode OTP.
5. Setelah menerima kode OTP, input pada kolom **Input OTP**.
6. Klik tombol **Proses**.

</Steps>

### Cetak SPM (Operator Pembayaran)

<Steps>

1. Buka menu **Pembayaran > Cetak > Mencetak SPM**.
2. Pilih SPM yang ingin dicetak.
3. Klik tombol **Unduh**.

</Steps>

### Upload dokumen pendukung (Operator Pembayaran)

<Steps>

1. Buka menu **Pembayaran > Catat/Upload > Upload Dokumen Pendukung**.
2. Pilih SPM yang akan diunggah dokumen pendukungnya.
3. Pilih jenis dokumen pendukung.
4. Klik tombol **Pilih** untuk memilih berkas yang akan diunggah.
5. Klik tombol **Upload**.
6. Berkas yang diunggah akan muncul.
7. Klik tombol **View** untuk melihat berkas yang telah diunggah.
8. Klik tombol **Hapus** untuk menghapus berkas yang telah diunggah
   sebelumnya.

</Steps>

### Setuju SPM (PPSPM)

Login sebagai pengguna PPSPM selaku approver pada modul Pembayaran.

<Steps>

1. Buka menu **Pembayaran > Validasi > Validasi SPM**.
2. Pilih SPM yang ingin divalidasi.
3. Klik tombol **Unduh Pra Cetak** untuk mencetak SPM yang akan
   divalidasi.
4. Klik tombol **Setuju**.
5. Klik tombol **Batal SPM** apabila ingin membatalkan validasi atas
   SPM yang sudah divalidasi; klik tombol **Batal Dokumen Pendukung**
   apabila ingin membatalkan dokumen pendukung yang telah diunggah
   sebelumnya.

</Steps>

### Membuat ADK SPM (PPSPM)

<Steps>

1. Buka menu **Pembayaran > ADK > ADK SPM OTP**.
2. Pilih SPM yang ingin dibuat ADK SPM; dapat memilih lebih dari satu
   sekaligus apabila diperlukan.
3. Klik tombol **Proses ADK SPM**.
4. Klik tombol **Req OTP via SMS** untuk meminta kode OTP.
5. Setelah menerima kode OTP, input pada kolom **Input OTP**.
6. Klik tombol **Proses**.

</Steps>

### Proses KPPN

Proses di KPPN mengacu pada Standar Operasional Prosedur pemrosesan
SPM menjadi SP2D pada KPPN.

### Mencatat SP2D (Operator Pembayaran)

<Steps>

1. Buka menu **Pembayaran > Catat/Upload > Mencatat/Upload SP2D**.
2. Pilih SPM yang ingin dicatat nomor SP2D-nya.
3. Klik tombol **Catat SP2D Otomatis**.

</Steps>

## Hasil yang diharapkan

Dokumen input SPP SPM LS Banyak Penerima BAST diproses menjadi
SP2D SPM LS Banyak Penerima BAST setelah seluruh tahap selesai.

## Ketentuan

- SPM LS Banyak Penerima 237 BAST diperuntukkan untuk tagihan non
  gaji non kontraktual, terutama tagihan yang menggunakan akun
  Belanja Modal/Aset (53).
- Sebelum merekam SPP, satker wajib merekam BAST Non Kontraktual
  terlebih dahulu.
- Perekaman BAST Non Kontraktual mengakomodir penginputan kode
  barang aset.
- Ketika memilih jenis SPP LS Banyak Penerima 237 BAST, pilih BAST
  yang telah dibuat sebelumnya.
