Perubahan User SAKTI meliputi perubahan user, perubahan kewenangan user,
nonaktif pengguna, dan perubahan data user. Perubahan dapat dilakukan pada
kondisi berikut:

- Terdapat penggantian pengguna (cuti, dinas luar, mutasi).
- Terdapat kesalahan isian pada data user yang telah didaftarkan (NIK, NIP,
  NPWP, email, No HP).
- Terdapat penambahan dan/atau perubahan kewenangan kelompok pengguna.
- Terdapat permohonan penonaktifan atau penghapusan user (pensiun).

## Prasyarat

1. SK Penetapan Pengguna SAKTI (PDF bertanda tangan).
2. Form Perubahan Pengguna SAKTI (PDF bertanda tangan).
3. Form Perubahan Pendaftaran Pengguna SAKTI (Excel).

Format dokumen dapat diakses melalui `bit.ly/saktiadm`.

## Pemutakhiran kewenangan khusus operator

Permohonan pemutakhiran kewenangan khusus operator menggunakan form yang sama
dengan ketentuan: kolom peran diisikan dengan **peran terbaru** yang
dibutuhkan (contoh pengisian nama peran seperti
`SATKER_OPERATOR_KOMITMEN` atau `SATKER_OPERATOR_PEMBAYARAN` sesuai petunjuk
pada `bit.ly/rolesakti`).

## Ketentuan

- Untuk perubahan user **Pejabat Perbendaharaan**, admin satker terlebih
  dahulu melakukan penghapusan Pejabat Perbendaharaan di referensi pejabat.
- Pastikan Pejabat Perbendaharaan tidak memiliki transaksi yang menggantung.
- Satker dan/atau KPPN dapat melakukan pengecekan transaksi pejabat melalui
  monSAKTI (menu admin – transaksiPejabat).

<Aside type="caution" title="Perlu verifikasi">
Juknis menyebut jalur menu pada monSAKTI sebagai "admin – transaksiPejabat";
pastikan label menu pada aplikasi saat digunakan.
</Aside>
