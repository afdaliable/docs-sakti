User SAKTI di Kanwil DJPb terdiri atas dua tipe: **tipe Satker** (modul
transaksional; role admin, operator, validator, approver) dan **tipe Kanwil
BUN** (fitur BUN, mengakomodasi validasi dan persetujuan revisi anggaran;
role validator dan approver). Artikel ini membahas pendaftaran tipe Kanwil
BUN.

## Kelompok pengguna

- Peran **Validator** selaku front office: `valkanwil_kodesatker_nip`.
- Peran **Approver** selaku back office: `aprkanwil_kodesatker_nip`.
- Peran **Admin** untuk pendaftaran user Kanwil K/L dan pengawasan revisi,
  yaitu pegawai Bidang SKKI: `admkanwil_kodesatker_nip`.
- Untuk akses monSAKTI pelaporan, pengguna Bidang PAPK mendaftarkan validator
  dan mendapatkan user `valkanwil_kodesatker_nip`.

## Alur pendaftaran

<Steps>

1. Kanwil DJPb selaku BUN membuat dan menyampaikan persyaratan pendaftaran
   (SK dan Form) user melalui tiket ke HAI-Kemenkeu.

2. Administrator Pusat (SITP) melakukan pengecekan dan proses pendaftaran.

3. Seluruh pengguna yang didaftarkan mendapat SMS berisi user ID dan kode
   akses SAKTI.

</Steps>

## Persyaratan

- Formulir Pendaftaran Pengguna SAKTI (Excel dan PDF).
- Surat Keputusan Penetapan Pengguna SAKTI (PDF).

Keduanya ditandatangani oleh **Kepala Kanwil DJPb**, yang menerbitkan surat
keputusan penetapan pengguna SAKTI paling kurang memuat nama pengguna, nomor
identitas, peran, dan jabatan pada aplikasi SAKTI.

Hal yang perlu diperhatikan saat mengisi formulir:

- No. HP harus valid dan aktif, diawali `0` atau `+` kode negara.
- Jumlah digit NPWP: **15**; jumlah digit NIK: **16**.
- Format semua kolom: *text*.
- Validator dan Approver boleh lebih dari satu.

Matriks peran untuk pendaftaran baru user SAKTI Kanwil DJPb (bukan selaku
satker):

| Fitur SAKTI Kanwil DJPb | Isian Peran di Excel | Level Pengguna | ID User |
|---|---|---|---|
| Modul anggaran | `KANWILBUN_VALIDATOR_ANGGARAN` | Front Office | `valkanwil_kodesatker_nip` |
| Modul anggaran | `KANWILBUN_APPROVER_ANGGARAN` | Middle Office | `aprkanwil_kodesatker_nip` |
| Pendaftaran user Kanwil K/L | `KANWILBUN_ADMIN_SKKI` | Seksi STA/UKI | `admkanwil_kodesatker_nip` |
| monSAKTI pelaporan | `KANWILBUN_VALIDATOR_PAPK` | Pengguna monSAKTI Pelaporan | `valkanwil_kodesatker_nip` |
| Login monSAKTI | `KANWILBUN_MONITORING` | Pegawai Kanwil DJPb yang membutuhkan akses monSAKTI di luar peran sebelumnya | `oprkanwil_kodesatker_nip` |

Keterangan:

- Seluruh user dengan kewenangan Kanwil (`admkanwil`, `oprkanwil`,
  `valkanwil`, `aprkanwil`) otomatis dapat mengakses monSAKTI dengan user
  SAKTI-nya.
- Pegawai yang sudah memiliki user SAKTI tipe Kanwil tidak perlu mendaftarkan
  kembali kewenangan `KANWILBUN_MONITORING`.
- `KANWILBUN_MONITORING` disediakan bagi pegawai Kanwil DJPb yang belum
  memiliki user Kanwil tetapi membutuhkan akses monSAKTI.

<Aside type="caution" title="Perlu verifikasi">
Juknis menyebut detail pendaftaran user Kanwil K/L di Kanwil DJPb masih dalam
proses pengembangan dan pembahasan.
</Aside>
