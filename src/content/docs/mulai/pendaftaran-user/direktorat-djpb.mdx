Pendaftaran user SAKTI level **Direktorat** pada Kantor Pusat DJPb mencakup
tipe Direktorat PA, Direktorat PPK BLU, Direktorat APK, Direktorat PKN,
Direktorat Sistem Perbendaharaan (SP), dan Setditjen. Saat ini level
Direktorat dan level pusat hanya memiliki peran **Approver** untuk
persetujuan, dengan user ID `aprpa_kodesatker_nip`.

## Prasyarat

- Formulir Pendaftaran Pengguna SAKTI (Excel dan PDF).
- Surat Keputusan Penetapan Pengguna SAKTI (PDF).

Keduanya ditandatangani oleh **Kepala Kantor atau Direktur**. Direktur
menerbitkan surat keputusan penetapan pengguna SAKTI, paling kurang memuat
nama pengguna, nomor identitas, peran, dan jabatan pada aplikasi SAKTI.

Hal yang perlu diperhatikan saat mengisi formulir:

- No. HP harus valid dan aktif, diawali `0` atau `+` kode negara.
- Jumlah digit NPWP: **15**; jumlah digit NIK: **16**.
- Kode satker dapat diisi menggunakan kode satker Kantor Pusat.
- Untuk Direktorat PA, isian peran di Excel adalah `DITPA_APPROVER_ANGGARAN`
  dengan ID User `aprditpa_kodesatker_nip`.

## Alur proses

<Steps>

1. Direktorat membuat dan menyampaikan persyaratan pendaftaran (SK dan Form)
   user melalui tiket ke HAI-Kemenkeu.

2. Administrator Pusat (SITP) melakukan pengecekan dan proses pendaftaran.

3. Seluruh pengguna yang didaftarkan mendapat SMS berisi user ID dan kode
   akses SAKTI.

</Steps>
