Pengguna monSAKTI tipe **Auditor BPK** didaftarkan oleh Direktorat APK DJPb
berdasarkan Surat Tugas BPK. Pendaftaran dilakukan di **monSAKTI** dengan
login menggunakan user SAKTI tipe Direktorat APK.

## Prasyarat

- Role yang dibutuhkan: user SAKTI tipe Dit APK dengan peran **Admin**
  yang sudah terdaftar pada SAKTI.

## Langkah

<Steps>

1. BPK menyampaikan **Surat Tugas** masing-masing ke Direktorat APK, DJPb.

2. Dit APK login ke monSAKTI menggunakan user SAKTI (*Single Sign-On*)
   dengan peran Admin.

3. Buka menu **Admin - Manajemen User** pada monSAKTI.

4. Klik tombol **Tambah**, lalu lengkapi data pendaftaran:
   - Peran User: **Audit** = BPK.
   - Tanggal aktif akun maksimal **6 bulan**.
   - Opsi pilih K/L hanya muncul setelah peran audit dipilih.

5. Auditor BPK didaftarkan dan di-assign oleh pengguna SAKTI tipe Direktorat
   APK di monSAKTI.

</Steps>

Pada menu Manajemen User, Dit APK juga dapat:

- **Melihat daftar K/L** yang telah di-assign/mapping pada user.
- **Reset password** pengguna.
- **Menghapus** akses pengguna.

## Ketentuan

- UserID untuk login BPK di monSAKTI adalah **NIK**.
- Password otomatis dikirimkan melalui email kepada email yang didaftarkan
  pada user BPK.
- Setelah login pertama kali menggunakan password default, user otomatis
  diarahkan untuk mengganti password awal; menu tidak dapat diakses sebelum
  password diganti. Setelah itu user login kembali dengan password baru.
- User BPK otomatis berstatus **nonaktif** apabila sudah berada di luar
  tanggal penugasan.
