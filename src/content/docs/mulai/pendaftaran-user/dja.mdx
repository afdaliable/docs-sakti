Tipe **DJA (pusat)** digunakan untuk user tipe DJA yang memiliki peran
non-satker, yaitu peran **penelaah** untuk keperluan penelaahan dan Direktur
Jenderal Anggaran. Persyaratan disampaikan sesuai
[alur pendaftaran tipe selain Satker](/mulai/pendaftaran-user/syarat-dan-alur/).
