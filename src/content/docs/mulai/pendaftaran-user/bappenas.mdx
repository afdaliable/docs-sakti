Pendaftaran user SAKTI tipe Bappenas diperuntukkan khusus bagi proses bisnis
pusat Bappenas dengan peran **Penelaah**.

## Prasyarat

1. SK Penetapan Pengguna SAKTI (PDF).
2. Form Pendaftaran Pengguna SAKTI (PDF dan Excel).

Persyaratan dikirimkan melalui **hai.kemenkeu.go.id** atau email
**hai.djpb@kemenkeu.go.id** menggunakan email kedinasan
(`@sakti.mail.go.id`/`@go.id`).

- Apabila menghendaki penggunaan SAKTI Mail, hubungi KPPN mitra satker untuk
  pendaftaran SAKTI Mail.
- Khusus Bappenas, data user diperkenankan menggunakan email
  `@bappenas.go.id`.
