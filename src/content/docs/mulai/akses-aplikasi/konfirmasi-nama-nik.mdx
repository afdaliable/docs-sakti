Nama dan NIK pengguna SAKTI sudah terinterkoneksi dengan data Kependudukan
Dukcapil. Konfirmasi data dilakukan untuk memastikan nama dan NIK cocok 100%
dengan data kependudukan pada penerapan login SAKTI dengan NIK.

<MenuSakti />

## Langkah

<Steps>

1. Login ke aplikasi SAKTI di **sakti.kemenkeu.go.id**.

2. Buka menu **Administrasi > Pengguna > Konfirmasi Data Nama dan NIK**.

3. Periksa tingkat kecocokan antara NIK dan Nama; nilai maksimal adalah 100%.

4. Untuk memperbarui, klik **Ubah Data**, lalu **Simpan**.

</Steps>

## Ketentuan

- Nama pada fisik KTP dapat berbeda dengan nama di database kependudukan.
- Pengecekan melalui aplikasi SAKTI dibatasi **6 kali sehari**.
- Pendaftaran user dapat dilakukan saat kecocokan data minimal **90%**
  (karakter `.` dan `,` diabaikan). Setelah itu, pengguna diminta melakukan
  konfirmasi hingga mencapai **100%** pada halaman awal aplikasi SAKTI.
- Apabila perubahan nama menghasilkan persentase kecocokan yang lebih rendah,
  aplikasi SAKTI otomatis mengambil data nama dengan tingkat kecocokan paling
  tinggi.

## Masalah umum

<details>
<summary>Konfirmasi gagal karena data NIK tidak sesuai</summary>

Hubungi Dukcapil setempat atau Halo Dukcapil **1500537**.

</details>
